操控脸上印着 AIX Logo 的小精灵，在币圈星空里疯狂手搓冲刺：100 米保本、每多 10 米多赚 10%、200 米翻倍、最远冲到 5 倍；途中会被各种原创设计的币种怪物和行情障碍突然砸停，玩的就是"差一点""不服输""再来一把"。

核心体感
• 双手离不开屏幕：中间狂点加油、左右躲避障碍，冲刺时像火箭一样窜出去。
• 赢面由系统比例控制：玩家全程觉得是自己手速和反应决定输赢，但整体输赢比例由后台设定（详见第五章），自动连点、模拟器无法改变结果。
• 越贪越刺激：100 米回本、200 米翻倍，是见好就收还是继续冲 5 倍？继续跑随时可能被一个币种怪物砸停、前功尽弃。
• 输得有乐子：死法全是币圈梗，每个障碍都有独立造型和幽默台词；亏了送安慰积分去抽奖，降低挫败、留住人。
• 快速销毁 AIX：没跑回来的 AIX 直接销毁，配合画面强化"通缩"叙事。

三、玩法规则
3.1 一局怎么玩
1. 选门槛：拖动 / 点选这一把消耗多少 AIX（1–100，自己定），点"开跑"。
2. 倒计时：3-2-1，小精灵从 0 米出发。
3. 奔跑（三个按钮，两只手）：
◦ 正中间最大的按钮「加油 / 奔跑 AIX」：要一直快速连点，点得越勤跑得越快；达到一定手速进入火箭冲刺（身后喷火、画面飞速拉远、音效上扬，像火箭窜出去）。手一停就掉速。
◦ 左边按钮：向左换道；右边按钮：向右换道。
◦ 赛道分左 / 中 / 右三条道，障碍会占住其中一两条，必须提前躲到空的那条。
4. 躲障碍：前方不断冒出各种原创币种怪物和行情障碍（见第六章），有实体障碍、全屏天气、必杀剧情之分。撞上致命障碍立刻终止。
5. 结果：按跑到的米数算倍率，把对应 AIX 带走；没到保本线则全损销毁，同时送安慰积分。
6. 再来一把：结果页大按钮"同上门槛，再来一把"，一键再来，把决策时间压到最短。
3.2 操作细节
• 底部三块触控区：左闪避 ｜ 加油（最大、居中、最醒目）｜ 右闪避。
• 手不能停机制：冲刺段经常要求"一边狂点加油一边左右躲"，变道的瞬间加油若停太久（容差约 0.2 秒，可调）就会踉跄失败——逼玩家双手绷紧。
• 反馈要足：按键回弹、手机轻微震动、连点火花、小人摆臂快慢随手速变化、冲刺时的推背感。
• 正常跑速度和疯狂点击的冲刺速度分别可调（见第八章），冲刺要有明显"嗖"一下冲出去的火箭感。
3.3 好玩在哪
• 狂点的操作爽感 + "我靠手速赢的"掌控感；
• 离保本 / 翻倍只差几米的惊险，和功亏一篑的不甘心；
• 币圈梗障碍的幽默，收集各种"奇葩死法"；
• 翻倍落袋 vs 贪心冲 5 倍的心理拉扯；
• 亏了有积分抽奖兜底，赢了有销毁通缩的爽感；
• 排行榜看别人能跑多远，激发攀比（榜单只展示、不发奖，见第九章）。

五、输赢比例与中奖控制（后台设定）
• 游戏整体的输赢比例由后台设置，建议默认方向：约 60% 的对局亏损、40% 的对局盈利，中间约 20% 的差额作为平台收益和销毁来源（具体比例随时可改）。
• 系统按设定比例安排每一局的结局米数和障碍，保证：
◦ 玩家操作体验是真的（要躲、要点、有反应空间）；
◦ 但全局返奖比例始终收在设定区间内，奖池不会被打穿。
• 可按门槛大小、新老用户、时间段做差异化照顾（例如新用户前几把更容易尝到翻倍甜头），但都设上下限、带随机扰动，避免被摸出规律。
• 自动连点器、模拟器狂戳无效：结果由系统比例决定，手速只影响画面表现，脚本无法提高胜率（作为产品规则写死，不给外挂留空间）。
• 后台需提供一个比例模拟 / 试算工具：运营改完参数，能一键模拟大量对局，提前看到"多少对局亏、多少赚、平均返奖多少、AIX 销毁多快、最高倍率出现频率"，确认没问题再生效。

六、障碍物：币圈主题 + 每个独立原创画面
核心美术要求：每一个币种障碍都必须独立设计专属画面，是有自己外形、性格、配色和动作的原创角色 / 装置，严禁"一个圆形硬币换个 Logo"的批量套皮。 玩家要能一眼认出"这是 BTC""这是 ETH"，但形象本身是为游戏原创的卡通角色，神似而不照搬官方标志（规避商标风险，见第十二章）。
6.1 独立原画设计规范（美术必须遵守）
1. 一币一形象：每个币种提炼其品牌色与大众记忆点，再做拟人化 / 怪物化原创设计，造型、体型、表情、道具各不相同。
2. 要有性格：每个障碍有明确"人设"（暴躁、阴险、笨重、狡猾、搞笑等），出场和撞击动作符合性格。
3. 成套动作：每个障碍至少交付 出场（预警）→ 逼近（待机/移动）→ 命中瞬间 → 消散 四段表现，并与小精灵的受击演出联动（被砸、被绊、被吸、被冻等）。
4. 统一世界观下的差异：全部障碍统一为 Q 萌夸张、描边扁平 + 轻立体的同一渲染风格，但剪影轮廓必须差异明显，缩小到车道尺寸也能区分。
5. 适配玩法：造型要能清楚表达"占哪条道、是实体还是全屏、是致命还是减速"；支持竖屏远 / 近两种视距下的清晰度。
6. 合规红线：币种符号、颜色、文字做原创化处理，不直接复制官方 Logo、不用完整官方图标。
7. 可扩展：后续新增币种 / 节日限定障碍时，沿用同一规范即可不断加入障碍库。
6.2 币种实体障碍（逐个独立画面设计 + 死法台词）
每个障碍：【独立造型】（外形、配色、性格、动作）＋撞停台词（可后台改）。
1. BTC 巨币砸顶（Bitcoin）
• 造型：一枚古铜金色的超重巨型硬币，正面是原创的怒眉"₿脸"，头顶一对小恶魔角，下落时疯狂旋转、带火星拖尾；体型笨重、压迫感强。
• 动作：从屏幕顶端锁定玩家所在车道垂直砸下，落地震出裂纹和金币四溅。
• 台词："冲太猛，被 BTC 砸了个包，失败！"
2. ETH 菱晶绊脚（Ethereum）
• 造型：一组蓝紫色半透明棱形水晶，像一只蹲在地上的水晶兽，棱角锋利、冷光流动；阴险地从跑道里"长"出来。
• 动作：玩家接近时突然凸起成绊脚棱锥，命中时小精灵脸朝下平拍。
• 台词："不好意思，被 ETH 绊倒了。"
3. LTC 快银飞弹（Litecoin）
• 造型：一枚银白色拉长的子弹 / 火箭，戴着酷酷的护目镜，身后拉出银色残影和速度线；性格高冷、极快。
• 动作：从侧后方斜向高速擦撞，几乎没预警时间。
• 台词："被 LTC 闪了一下，遗憾退场。"
4. BNB 黄箱天降（BNB）
• 造型：一个明黄色方正集装箱 / 方块怪，四角包铁、表情木讷，方方正正毫不讲理。
• 动作：整箱横着砸下，直接封死一到两条车道。
• 台词："被 BNB 黄箱拍地上了。"
5. SOL 卡顿地刺怪（Solana）
• 造型：紫青绿色渐变的像素方块怪，身体时不时"加载失败"打成马赛克，脑门上亮着一个红色离线叉号。
• 动作：出现时画面假装卡顿，随即从地面弹起一片像素尖刺。
• 台词："网络拥堵，SOL 宕机把你送走了。"
6. XRP 水龙卷（Ripple）
• 造型：一条由蓝色同心圆波纹组成的水龙 / 小型龙卷风，波纹层层扩散，半透明带水花。
• 动作：在车道间游走盘旋，碰到即被卷上天。
• 台词："被 XRP 水龙卷卷走了。"
7. DOGE 柴犬冲撞队（Dogecoin）
• 造型：领头是一只戴金链子、表情魔性嚣张的胖柴犬，后面跟着一串大小不一、吐舌头的柴犬。
• 动作：成群结队轰隆隆迎面冲撞，占满多车道。
• 台词："被 DOGE 柴犬大军撞翻了。"
8. SHIB 柴犬海（Shiba Inu）
• 造型：比 DOGE 更瘦小、眼神更凶的红头巾柴犬，数量极多、密集成海浪。
• 动作：像潮水一样整片涌来淹没车道。
• 台词："掉进 SHIB 柴犬海里了。"
9. PEPE 青蛙弹幕墙（Pepe）
• 造型：一张张经典绿青蛙大笑脸，压扁成弹幕墙层层飞来，表情夸张、眼睛凸出。
• 动作：全屏横向飞脸，缝隙里找空车道。
• 台词："被 PEPE 青蛙脸糊住了。"
10. ADA 紫龙虾（Cardano）
• 造型：一只紫色学术风大龙虾，戴单片眼镜、举着两只不对称的大钳子，表情一本正经。
• 动作：横在路中间双钳夹击，要在钳口开合的间隙通过。
• 台词："被 ADA 龙虾夹住了。"
11. TRX 红能冲击波（TRON）
• 造型：披着红色披风的能量武士，挥手放出红色月牙形冲击波。
• 动作：红色波刃横扫，必须躲到反方向车道。
• 台词："被 TRX 红色能量波掀飞了。"
12. DOT 波卡链球（Polkadot）
• 造型：一颗粉色主球牵着一串小圆点连成的链锤 / 摆锤，圆点一张一合像在呼吸。
• 动作：像钟摆一样在车道上方来回扫动。
• 台词："被 DOT 链球扫中了。"
13. MATIC 紫色尖刺（Polygon）
• 造型：一排紫色多边形（三角形为主）水晶地刺，棱角锐利、成排竖起，像一只蜷缩的紫色刺猬展开。
• 动作：在某条车道连续冒刺，逼玩家提前变道。
• 台词："被 MATIC 紫刺扎停了。"
14. ATOM 原子分裂怪（Cosmos）
• 造型：一个悬浮的原子球机器人，核是发光的眼睛，电子轨道环旋转；分裂时向三车道同时迸射小碎片。
• 动作：接近时突然分裂，碎片多方向飞散。
• 台词："ATOM 一分裂，躲无可躲。"
15. XMR 隐身黑影（Monero）
• 造型：一团纯黑斗篷形怪物，只露出两只发光眼睛，身体半透明、几乎融进背景。
• 动作：隐身逼近，在玩家身前突然显形撞击。
• 台词："XMR 隐身怪，根本没看见它。"
16. FTM 鬼影（Fantom）
• 造型：半透明青蓝色漂浮幽灵，拖着长尾巴，表情哀怨，身体可穿墙。
• 动作：从跑道地面慢慢飘起拦路。
• 台词："被 FTM 鬼影飘了一下。"
17. NEAR 传送门（NEAR）
• 造型：一道霓虹彩虹色圆环传送门，门内是扭曲星空，看起来像加速道具其实是陷阱。
• 动作：玩家穿过去会被随机甩到另一条车道的障碍上。
• 台词："以为是近道，结果被 NEAR 门坑了。"
18. ARB / OP 双色卷轴（Arbitrum / Optimism）
• 造型：两卷分别蓝色、红色的 L2 卷轴，像两卷会跑的地毯，在高速路口交错缠绕。
• 动作：两条卷轴交替卷动封锁车道。
• 台词："在 L2 高速路口被卷轴卷走了。"
19. INJ 注射针（Injective）
• 造型：一支巨型金属针筒怪，针尖反光、筒内是绿色液体，表情疯狂。
• 动作：从车道斜刺而出（呼应行情"插针"）。
• 台词："被一根 INJ 大针插停了。"
20. TIA 模块化陨石（Celestia）
• 造型：橙紫色的方块状陨石，表面像数据模块一样层层拼接、燃烧着火焰。
• 动作：成雨状从右上方密集坠落。
• 台词："撞上 TIA 陨石雨了。"
21. 土狗动物园（各种动物币）
• 造型：一只由猫、狗、蛙、龙、仓鼠等山寨动物拼装的"缝合兽军团"，画风粗糙搞怪、五颜六色。
• 动作：乌泱泱无纪律地成群冲锋，随机占道。
• 台词："被一群土狗动物军团踩过去了。"
6.3 稳定币天气 / 怪物（全屏范围，独立设计）
1. USDT 雨 / 冰雹 / 暴风雪（Tether）

七、AIX 消耗、销毁与安慰积分
7.1 参与门槛
• 开一局只消耗 AIX，不支持任何其他币、不设币种白名单。
• 每把门槛自选：最低 1 AIX、最高 100 AIX，步进默认 1（上下限可调）。
• 支持"同上门槛再来一把"快捷操作。
7.2 AIX 的去向
• 跑回来了：按倍率把 AIX 带回账户（100 米保本、200 米翻倍、最高 5 倍）。
• 没跑回来（全损）：消耗的 AIX 处理方式由后台按比例分配，建议大头用于销毁，其余作为平台 / 活动储备；销毁打入统一黑洞地址。
• 结果页和个人记录展示"本局销毁 X AIX / 全网累计销毁 X"，强化通缩和参与感。
7.3 安慰积分与抽奖（积分唯一用途）
• 没跑到保本线时，按消耗门槛送一定安慰积分（比例、每日上限可配）。
• 积分只能用于抽奖，不能转让、不能交易、不能兑换成 AIX 提现。
• 抽奖形式建议：大转盘 / 盲盒，奖品池后台配置，例如：
◦ 少量 AIX 奖励（严格控制总量和概率）；
◦ 小精灵皮肤、拖尾、冲刺特效等装扮；
◦ 复活券、保险券等下一局道具（是否影响平衡由后台开关）；
◦ 抽奖加成、限定表情 / 头像框；
◦ "谢谢参与，再跑一把"。
• 各奖品概率可配、可公示；每日抽奖次数 / 免费次数可配。目的是让没跑回来的玩家有慰藉、愿意留下继续玩，不形成新的资金出口。

八、运营后台需要能调的参数（灵活配置清单）
所有参数可视化配置、能改默认值、能设取值范围、修改有记录、可随时回滚；并配第五章的"模拟试算"。
参与门槛：最低（默认 1）、最高（默认 100）、步进；两次开跑间隔、单地址每日上限（防沉迷 / 风控用，可关）。
收益曲线：保本线（100 米）、翻倍线（200 米）、全损线（100 米前全损）；每多少米加多少收益（默认每 10 米 +10%）、零头取整方式；基础封顶（2 倍）、最高封顶（5 倍）、极限区步长与增益；过 200 米是否锁定 2 倍保底（默认开）；是否对"50–100 米"给部分返还（默认不给、全损，保留开关）。
输赢比例：各结局档占比（默认全损 60%）、目标整体返奖比例；按门槛档位 / 新老用户 / 时间段的差异化比例与随机扰动；新用户前几把保护（默认开）；奖池安全线，紧张时自动收紧赢面。
速度与操作：正常跑速度、最高连点速度、火箭冲刺速度；进入冲刺所需手速、闪避时允许的加油断连容差；车道数（默认三道）。
障碍与场景：每个障碍的出现概率、车道、致命 / 减速、最早出现米数、所属场景、台词；障碍随米数变密的节奏曲线；各场景出现概率与专属障碍池；失败台词库（可随时加梗）。
销毁与积分抽奖：全损 AIX 的销毁 / 平台 / 活动分配比例；销毁地址；安慰积分赠送比例与日上限；抽奖奖品池、各奖品概率、每日次数。
排行榜（只展示）：榜单周期（默认每日，另有总榜）、时区；榜单维度（最远距离 / 最高倍率）；虚拟玩家数量、昵称、成绩区间、占比（见第九章）。

九、排行榜（只看，不发奖）
• 排行榜纯展示，没有任何奖励（不发 AIX、不发倍率、不发道具），只用来制造攀比和谈资。
• 默认每日榜（定时刷新、重置），另设总榜；维度为最远距离和最高倍率。
• 榜单展示：排名、昵称（虚拟地址或昵称）、最远距离 / 最高倍率、所在场景。
• 可放虚拟玩家：后台生成一批真实地址样式的虚拟账号和合理成绩填充榜单、营造人气，真实玩家跑出好成绩可把他们挤下去；虚拟账号仅用于展示、不参与任何实际资金。
• 所有成绩以系统结算为准，杜绝伪造成绩上榜。
