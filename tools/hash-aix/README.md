## 游戏设计

参考常见哈希游戏的「单双 / 大小」选择方式，用原创的晶体星盘呈现回合。产品包含四个独立视图：

1. **哈希星盘**：0–F 数字盘、选项归属高亮、手动快速回合、揭晓、结算卡与最近回合。
2. **我的记录**：最近 100 个本机实际模拟回合，参与/命中筛选、星点统计及 JSON 导出。
3. **结果核验**：完整种子和哈希、重新计算、复制凭证，以及粘贴凭证的独立一致性核验。
4. **玩法指南**：全部数字归属、概率与返还示例、玩家种子、快速/定时模式与减少动态设置。

桌面采用侧边导航与左右双栏；手机使用底部导航与单列内容。在 390 × 844 首屏能看到完整确认按钮；结算后收起重复信息，结算明细与下一回合按钮同屏。音效默认关闭，开启后通过 Web Audio 合成。没有自动连续参与，也没有虚构的玩家或开奖记录。

## 游戏大厅

大厅 v3 由游戏前端工程师重做、游戏 UX 工程师复核。采用紧凑侧栏、160 px 精选横幅、两张主游戏卡和「我的游戏」侧架。手机使用 118–126 px 横幅与双列游戏卡，两款游戏的名称和完整开始按钮在首屏可见；开始与收藏按钮均有 44 px 触达区域。使用明确的游戏名称和玩法说明，减少装饰文字。沿用现有原创星门、跑酷和星盘资产，本次没有新增图片生成费用。

包含游戏大厅、我的收藏、游玩记录、新手指南四个视图，支持分类、搜索、清空、无结果状态、收藏持久化和上次打开入口。两张游戏卡片都有真实可游玩入口，没有占位游戏或虚构在线人数。手机顶部提供可见返回 AxiX 箭头，独立页面返回主页，嵌入网站时关闭游戏空间。

大厅读取跑酷关卡/星级与星盘参与统计，分别展示；不会启动或结算星盘，也不更改跑酷进度。「最近打开」只记录点击入口，与实际参与统计区分。大厅收藏和打开记录保存在 `aix-play:lobby:v1`，存储不可用时显示提示并保留本页操作。

网站入口使用同源 iframe 弹窗。桌面居中，手机全屏，保留独立窗口与关闭按钮；关闭/ESC 后恢复焦点与背景滚动。大厅的返回按钮可关闭嵌入空间，两个游戏在空间内互相跳转。

## 公开规则

默认快速回合：开始即公开承诺，等待用户选择，不自动揭晓；确认后锁定并用 1.6 秒揭晓，也可以点击「先看一局」不消耗星点。指南里可切换为 15 秒选择、3 秒锁定的定时模式，从下一回合生效。每局只选一项、只确认一次；下一回合手动开启。初始 1,000 星点，每局参与 1–100 个整数星点。余额低于 100 且没有待结算参与时，可以手动免费补充至 1,000。

最终 SHA-256 的最后一个十六进制字符转换为数字 `0–15`：

| 选择 | 命中数字 | 单项理论概率 |
| --- | --- | --- |
| 单 | 1、3、5、7、9、B、D、F | 50% |
| 双 | 0、2、4、6、8、A、C、E | 50% |
| 小 | 0–7 | 50% |
| 大 | 8–F（8–15） | 50% |

命中返还 **1.98 倍，包含本局参与额**；未命中返还 0。参与 10 星点，命中返还 19.80、净增 9.80；未命中净减 10。理论返还率为 `0.5 × 1.98 = 99%`。历史结果不改变下一回合的概率。结果计算不读取玩家的预测或参与额。

星点内部以整数百分位记录，扣除、返还和免费补充分别计账。未参与回合只记录结果，不扣返星点，不记为命中或未命中。

## 哈希计算与核验含义

```text
seed       = crypto.getRandomValues 生成的 32 字节随机数，以小写 hex 表示
commitment = SHA256(seed)
finalHash  = SHA256(seed + ":" + clientSeed + ":" + nonce)
digit      = parseInt(finalHash 最后一位, 16)
```

`SHA256` 的输入编码为 UTF-8。回合开始先公开承诺、玩家种子和回合序号；揭晓后显示完整种子与最终哈希。修改玩家种子只作用于之后新建的回合。

这是浏览器本地模拟，没有读取真实区块或链上交易。凭证核验只证明承诺、哈希、判定与返还的计算一致；它不认证运营方，也不是服务端防篡改或链上证明。本机存档可被浏览器使用者查看和修改。

## 代码与存档

- `resources/app/public/hash-aix.html`：页面结构。
- `resources/app/public/games/hash-aix/game.css`：桌面、手机和减少动态效果样式。
- `resources/app/public/games/hash-aix/main.js`：界面控制、导航、记录导出、音效与核验交互。
- `resources/app/public/games/hash-aix/core.js`：随机种子、计时、扣返、持久化和核验。
- `resources/app/public/games/hash-aix/assets/hash-core.jpg`：实际使用的主视觉。

存档键为 `hash-aix:local:v1`，设置键为 `hash-aix:settings:v1`，与跑酷进度分离。保持 version 1，旧版无 `mode` 字段的记录/待结算回合仍按定时模式恢复与核验。新版回合有 `mode: 'quick' | 'timed'`。快速回合未确认时 `closesAt/revealsAt` 为 null，确认/仅查看后固定为操作时间及其后 1,600 ms。旧记录与新记录可混存，不重置余额和历史。

刷新会恢复同一回合；已锁定且过期的回合在页面重新激活后结算一次。未确认的快速回合不会自动消耗星点、自动结算或生成历史。Web Locks 可用时协调同源标签页；其余浏览器使用存档版本冲突检查，建议单标签试玩。若系统时钟退至本局创建之前，暂停确认并提示检查时间，保留存档。

存储不可用时允许当前页面以内存继续试玩，并显示持久化限制。读取到不一致存档时保留原始内容、暂停游戏并显示错误，不自动清空或补分。
