# 主站多语言检查结果

检查日期：2026-10-10

范围：主站 7 种语言（简体中文、繁體中文、English、日本語、한국어、Русский、Español）。未检查后台和单独宣传页，也未执行部署。

## 已修复

- 修复首次切换语言时词典不完整导致的中外文混排。
- 修复动态文本、数量、金额、占位符、标题和提示框翻译；保留订单金额、数量、地址、时间戳和钱包签名原文。
- 修复矿机、质押、团队、抽奖、资金费率、交易术语、收益明细、推荐数据等主站文案。
- 修复社交推广弹窗：显示文案、复制内容和 Twitter 分享链接会随语言同步。
- 修复动态 BNB 期限、收益统计、撤单数量和网格确认信息的变量翻译。
- 更新静态资源版本号，避免旧缓存继续使用旧词典。
- 调整顶部布局，避免较长外语导航挤压品牌名和时钟换行。

## 验证

- `test/i18n.test.js`：通过。
- `test/trade-history.test.js`：通过。
- 主站页面审计：21 个主站/二级页面，1,043 条中文源文案，6 种目标语言 residual 0，fallback 0，页面错误 0。
- 社交弹窗、确认框、提示框：7 种语言通过，金额和变量保留。
- 桌面 1440px 与移动 390px：7 种语言无横向溢出。
- JavaScript 语法检查：通过。

页面审计使用隔离浏览器和只读合成测试数据展开需要登录的二级视图，不会写入账户、交易、支付或链上状态。
