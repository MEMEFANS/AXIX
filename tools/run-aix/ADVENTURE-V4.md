# 奔跑吧 AIX · 本地冒险版 V4

本轮把原先单页概率试玩扩展为免费操作闯关游戏。所有进度在当前浏览器保存，未部署生产。

## 游戏流程

- 主大厅：继续冒险、新手训练、世界入口、旅程星数、每日远征。
- 世界选关：三个世界、六个关卡，距离为 200 / 250 / 300 / 350 / 400 / 500 米；完成前关解锁后关。
- 训练：固定道路、两排单车道障碍、四个星晶；分自动奔跑、换道、收集三阶段引导，不要求加速。
- 操作：自动巡航，左右按钮 / 横向滑动 / 键盘换道，按住按钮或空格加速；松手仍前进。
- 容错：三颗心，实体碰撞扣心，受击后保护一秒；首关前 50 米保护。天气与泥潭减速、打断完美成绩，但不扣心。
- 星级：通关一星，受击最多一次得二星；无受击且收集至少 75% 的可达星晶得三星。
- 收藏：三款配色外观，0 / 6 / 12 星解锁；七种真实进度徽章。
- 成绩：关卡最佳、总次数、累计星晶、最高连击；每日远征固定中国日期的种子，可重试并记录当日最佳。
- 设置：音乐和音效、触感、减少动态效果。首次使用尊重系统减少动态效果偏好。

## 与旧概率试玩的关系

默认入口 `/run-aix.html` 是免费操作冒险，不预抽胜负、不读写模拟积分或真实 AIX。独立概率试玩保留在 `/run-aix-classic.html`，其公开比例、账本与配置页仍保留。`/run-aix-config.html` 只影响该独立试玩，不改变战役难度和障碍。

已有 classic 存档不会被迁移或清空。新进度使用 `run-aix:player-profile:v1`；未完成的免费冒险刷新后回大厅，可以重新开始。存储被禁用时当前页面仍可玩，但刷新不保证保留。

## 工程入口

| 模块 | 职责 |
| --- | --- |
| `adventure.js` / `adventure.css` | 页面路由、关卡流程、输入、弹窗与 HUD |
| `campaign.js` | 世界、关卡、训练与独立主题障碍配置 |
| `campaign-engine.js` | 基于既有引擎的生命、保护、连击、星晶及星级 |
| `player-profile.js` | 主线解锁、外观、徽章、每日成绩和设置 |
| `art.js` | 世界固定场景、星晶投影、角色配色与受击保护表现 |

沿用现有角色八帧动画、三套背景、16 种障碍与合成音频。新增大厅图来自之前已配置的卡扣媒体 API，`gpt-image-2`，费用 USD 0.20。成品 `assets/hub-v4.jpg` 1200×800，约 167 KB；原图、完整提示词、任务与费用记录见 `art-jobs/hub-v4-manifest.json` 和 `art-jobs/hub-v4-prompt.txt`。

## 验证与本地运行

```powershell
node tools/run-aix/preview.mjs
node tools/run-aix/campaign-check.mjs
node tools/run-aix/player-profile-check.mjs
node tools/run-aix/rules-check.mjs
node tools/run-aix/v3-engine-check.mjs
```

浏览器测试 `adventure-browser-check.mjs` 仅可连接独立测试配置的 Chrome（默认 CDP 9233），会重置该浏览器的冒险进度。它通过普通换道输入和不超过 50ms 的真实引擎更新推进对局，结果见 `adventure-browser-results.json`。不代表真人手感验证。引擎的 144 局检查覆盖六关、20/30/60 FPS、0.4 秒操作间隔。

本轮验证：冒险引擎 10 项、本地进度 13 项、浏览器整合 18 项通过。浏览器包含真实鼠标按住/松开加速、横滑、暂停清除按住状态、跨午夜每日归档及 320 / 390 / 1440 三种屏宽。独立概率试玩 7 组浏览器回归通过。通用 CDP 客户端改用 Node 原生 WebSocket，避免旧手写连接在输入测试中超时。

当前成果是可本地试玩的完整冒险循环，仍需真实手机与钱包 WebView 手感测试。云存档、公共排行榜、更多关卡、完整 60+ 障碍和在线运营发布不在此次完成范围。
