# 比例与难度调整 V4

参考：2026-10-19 浏览并操作 [Subway Surfers / SYBO on Poki](https://poki.com/en/g/subway-surfers)，检查其实际跑酷画面。参考小角色、前方路面视野和随进度提速的节奏，未使用其素材。参考截图只保存在本地 tools 目录。

游戏中角色尺寸从画布宽度的 27% 参数改为 15%，约缩小 44%；小高度画布额外按高度限制尺寸。大厅角色保持展示比例。

独立 `difficulty.js` 管理自动加速、连点增益及障碍队列：

| 距离 | 不点击时目标速度 | 火箭目标速度 |
| --- | --- | --- |
| 0 m | 10.0 M/S | 24.0 M/S |
| 100 m | 15.1 M/S | 29.1 M/S |
| 200 m | 19.2 M/S | 33.2 M/S |
| 350 m | 24.8 M/S | 38.8 M/S |
| 500 m | 30.0 M/S | 44.0 M/S |

速度平滑追随目标；检查点冻结、暂停冻结，释放连点只撤销额外增益。500 m 仍为既有终点。

障碍排间距从 34 m 收紧至 22 m；生成时间至少间隔 0.8 s。100 m 后逐渐引入双车道障碍（约 29% 至 65%），每排最多两道，始终保留通道，相邻规划安全道最多移动一格。未增加隐藏胜负控制。

验证：15 项引擎测试（含 1000 局随机操作、3000 排安全通道检查、100 局全速预判避障及 100 局挂机对照），9 项浏览器交互，9 项完整流程，4 项美术资源，6 项运动检查，共 43 项。新的角色比例实机录像为 `run-v4.webm`。仅本地测试，未部署；没有新增图片 API 调用或费用。
