# V3 本地实现对照 · 2026-10-20

依据：桌面文件《奔跑吧AIX_游戏需求文档_v3.md.docx》（V3.0，12章）。正文及表格提取副本为 `output/game-doc-review/requirements-v3.txt`。此文件记录本轮本地开发状态，不改写原需求文档。

## 已确定的规则

| 原文分歧 | 本轮采用 |
| --- | --- |
| 正文“60%亏、40%盈”与明细“60%全损、15%保本、25%盈利”冲突 | 用户明确选择明细表：60 / 15 / 18 / 6 / 1；可在本机配置页修改 |
| “每10m +0.1”与部分表格“220m=2.1 / 每20m +0.1”冲突 | 统一按每10m +0.1，100m=1、200m=2、500m=5 |
| “全损全部销毁”与“大头销毁、其余平台/活动储备”并存 | 默认全损100%模拟销毁，平台/活动0%；分配合计须100%，支持修改 |
| 建议约20%差额与五档结果模板不一致 | 不强行宣称80%返还；默认等额理论返还57.55%，在配置页计算并展示 |

默认档内分布：全损结果在20–99m整数米；保本在100–109m；小赚1.1–1.9倍；翻倍2倍；高倍2.1–5倍。每档内按候选米数等概率。最高5倍的基础概率约0.0333%，高倍档合计为1%。

模板返还期望：`0.60×0 + 0.15×1 + 0.18×1.5 + 0.06×2 + 0.01×3.55 = 0.5755`。试算按每局1积分等额、不提前收取、不叠加新手保护；实际试玩结果可能不同。

概率模式开局抽取结果区，并在大厅、规则和结算中公开说明。提前普通碰撞只减速，停点会踉跄停步，继续点击可恢复；到抽中的结果区结束。操作不会把抽中的全损提高为盈利。另提供操作挑战模式，致命碰撞与断连直接结束，不预抽结果。

新手保护支持配置保护局数；为保留默认五档基础分布，默认关闭。开启后保护期抽中全损提升为保本，界面明确说明实际分布改变。

## 本地数据

- `run-aix:v3:rules`：本机规则及历史。
- `run-aix:v3:catalog`：本机障碍库及历史。
- `run-aix:practice:v1`：沿用原键，账本结构迁移至version3，保存试玩/安慰积分、进行中存档、结算、抽奖、模拟分配和榜单。

新局开始读取最新配置，过程中不改规则。刷新恢复沿用原局ID、门槛、规则、障碍目录和目标，不再扣一次。无法恢复的旧存档可作废，不返还门槛、不额外发安慰积分。清除浏览器数据会清除这些本机记录；存储受限时仅能保留页面内状态。

抽奖奖品固定公示：谢谢参与60%、5试玩积分25%、20试玩积分10%、星光装扮本机收藏5%。安慰积分不能转出或兑换真实AIX，收藏装扮当前只入本机收藏，尚未提供皮肤装备系统。

## 验证记录

- 规则模块：6组，含10万局试算及曲线/配置校验。
- 障碍库模块：5组，含非法配置、独立版本历史与损坏数据回退。
- 障碍整合：5组，禁用/权重/距离/场景/车道和每局快照；1:9权重抽样2万个障碍，实际BTC占9.935%。
- 模拟账本：12组，含幂等、日界、限额、恢复与分配。
- V3引擎：11组，含1200局结果一致性、五档覆盖、20/30/60FPS操作挑战、检查点、碰撞和存档。
- 道路回归：17组，含随机压力和全速道路。
- 浏览器整合：7组，含75m刷新恢复旧规则及下一局新规则、完整全损抽奖与500m返还、320/390屏宽；运行异常0，账户仅GET profile。
- 结算异常分支：覆盖重复结果幂等、不一致结果拒绝、失败后恢复未完成局和存储写入失败的页面内抽奖提示，运行异常0。
- 已有未完成局：模拟另一标签建立pending，当前页开局提示恢复；重载保持原ID、余额及局数，无重复扣分，运行异常0。
- 配置页：编辑、持久化、错误提示、试算、回滚/重置；320至1440共7种屏宽无横溢出。
- 绘制与音效：浏览器执行16种障碍四阶段、受击/天气及AudioContext，无运行异常。

执行入口见README。相关报告为 `v3-engine-results.json`、`v3-browser-results.json`、`v3-settlement-browser-results.json`、`v3-pending-browser-results.json`、`catalog-integration-results.json` 及各模块检查输出；旧V2/V5报告保留为历史，不代替本轮验证。

## 当前交付边界

本轮实现可玩的V3阶段版本，未部署到服务器。真实AIX仅沿用网站账户只读显示；不签名、不授权、不扣返、不发链上交易。对局和概率状态可在浏览器修改，因此不能作为真实资产结算依据。

要形成真实资产版本，仍须接入服务端权威对局、持久幂等账本、奖池及权限后台、真实销毁核验、公共榜单，并继续补足障碍/场景/美术和移动钱包验收。先前BNB矿机轮换与统计属于独立任务，本轮未改动或部署该业务。
