# 钱包地址与矿机页面状态不同步：本地修复说明

日期：2026-10-10

## 原因

顶部拿到钱包地址后立即显示连接成功；矿机页面还需要平台身份签名登录完成。旧游客按钮始终写成“连接钱包后激活”，因此已连接但签名取消、未完成时也会被误显示为未连接。

登录完成后，旧页面还会等待个人数据接口返回；较慢的旧未登录响应或 401 也可能覆盖新的登录状态。切换账户或断开钱包时，旧矿机请求还可能迟到。

## 修复后的行为

| 状态 | 激活按钮 |
| --- | --- |
| 尚未连接钱包 | 连接钱包后激活 |
| 已连接，身份签名尚未完成或取消 | 钱包已连接 · 确认身份后激活（点击可重试验证） |
| 身份验证完成 | 立即激活，或根据已有记录显示已激活 / 激活确认中 |

钱包状态变化会立即通知矿机页面刷新，不必等个人数据接口全部返回。钱包和交易请求携带请求开始时的状态版本，过期的 401 不会清除新的登录。当前会话真正过期时仍会回到待验证状态。

断开或切换账户会清空页面个人缓存并使旧请求失效；签名期间更换账户时，不会提交旧账户的签名。新增提示已补齐主站全部 7 种语言，并更新前端资源缓存版本。

## 验证

- `node resources/app/test/earn-wallet-state.test.js`：地址恢复、取消签名、手动重试、慢请求期间及时显示已认证按钮、旧钱包与交易 401、当前会话失效、断开请求竞态、签名期间切换账户、7 种语言均通过。
- `node resources/app/test/i18n.test.js`、钱包连接器和钱包会话测试通过；修改的 JavaScript 语法检查通过。
- 全站翻译页面审计：6 种目标语言中文残留、回退与错误均为 0。
- `node tools/wallet-state-audit/preview.cjs`：本地主站 390px 手机布局验证，7 种语言页面宽度均为 390px。两张截图分别对应已连接待验证和身份验证完成。

截图使用隔离浏览器和模拟钱包，预览阻止全部非 GET API 请求，没有真实签名、付款或链上交易。

钱包会话测试的模拟 RPC 地址原为空，导致测试无法选择模拟 provider；已补为测试专用地址，测试仍只调用模拟 provider，不访问外部 RPC。
